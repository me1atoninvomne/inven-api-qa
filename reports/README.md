# Test run reports

Reports are generated by Newman and are not written by hand.

```bash
# 1. start the API (in the store-inventory-api folder)
./gradlew bootRun

# 2. in this repository: run the collection and save an HTML + JUnit report
npm install -g newman newman-reporter-htmlextra
newman run postman/store-inventory-api.postman_collection.json \
  -e postman/local.postman_environment.json \
  -r cli,htmlextra,junit \
  --reporter-htmlextra-export reports/newman-report.html \
  --reporter-junit-export reports/newman-junit.xml
```

Open `reports/newman-report.html` in a browser to see every request, response and assertion.
Commit the generated report together with a short summary in `reports/test-summary.md`
(date, API version, number of requests / assertions, passed / failed, bugs found).
